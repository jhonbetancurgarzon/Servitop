# 🛠️ Servitop - Soluciones Técnicas Integrales

Este repositorio contiene el código fuente y la arquitectura web del portal oficial de **Servitop**, una empresa especializada en diagnóstico y reparación técnica de electrodomésticos y equipos electrónicos.

## 🚀 Sobre el Proyecto
El portal ha sido diseñado para ofrecer una experiencia rápida y eficiente a nuestros clientes, facilitando la solicitud de servicios técnicos y proporcionando información detallada sobre nuestra cobertura en la región de Antioquia.

## 💻 Tecnologías Utilizadas
* **Lenguajes:** HTML5, CSS3, JavaScript.
* **Infraestructura:** Gestión de DNS a través de Cloudflare.
* **Hosting:** Despliegue automatizado mediante GitHub Pages.

## 📁 Estructura del Repositorio
* `index.html`: Página de inicio y centro de contacto.
* `reparacion-*.html`: Páginas de aterrizaje optimizadas (Landing Pages) para servicios específicos (lavadoras, neveras, televisores, etc.) y ubicaciones geográficas.
* `sitemap.xml`: Mapa del sitio para mejorar el posicionamiento en buscadores (SEO).

## 📊 Estado del Proyecto
Este proyecto se encuentra bajo constante mejora y optimización de rendimiento. Actualmente, nos enfocamos en la integración de herramientas de seguimiento para mejorar la conversión de clientes potenciales.
